# Your Groccery Store

### **Project Description**

Your Grocery Store is a web-based e-commerce platform designed for managing grocery store operations seamlessly. The platform provides essential features for customers, administrators, and employees, including product browsing, customer order management, and detailed sales reporting. Built with a focus on scalability, security, and functionality, this system is an all-in-one solution for modern grocery businesses.

Docker was used to containerize the application for consistent deployment and easier scalability, ensuring seamless integration across different environments.

## Key Features

* **Customer Management:** Secure login system to authenticate customers and administrators with password protection.

* **Product Catalog:** Customers can browse through a list of products with real-time updates.
* **Cart and Checkout System:** Allows customers to add products to their cart and complete transactions securely.
* **Admin Dashboard:** Administrators can:
    * Add and manage new products.
    * View customer details and orders.
    * Generate daily sales reports.
* **Sales Reporting:** Displays a graphical summary of daily sales using Chart.js.
* **Error Handling:** Provides informative error messages for incorrect login credentials or unauthorized access attempts.
* **Dockerized Deployment:** The application, including the database and backend, is containerized for consistent and portable deployment. 

## Tech Stack
